# Decision card template (tier 2)

> Generated by `scripts/gate-eval.mjs` (PA-01) or written by the AI Assistant by hand until then. One card, one decision, one screen on a phone.

```
CARD: <ADR-10 | G2 | G3 | G4 | ENABLE_MODEL_PATCH | SPEC-P19x | SPEC-P25>
DATE: <YYYY-MM-DD>   COMMIT: <sha>   CI: <link>
RULE: <section of the TZ applied, one line>
EVIDENCE:
  <step id> | <PASS|FAIL|BLOCKED|NOT_RUN|REAL_ONLY|OWNER_ATTESTED|scripted_human_step> | <record path or link>
  ...
RULE RESULT: <POSITIVE | NEGATIVE | BOTH_FAILED | INSUFFICIENT_EVIDENCE | NEEDS_HUMAN>
RECOMMENDATION: <ACCEPT | REJECT | COLLECT_MORE> — <one-sentence reason>
DEVIATIONS FROM THE TZ: <none | list; each must be accepted explicitly>
IF ACCEPTED, THE AI ASSISTANT WILL: <exact file changes, e.g. ADR-10 status ACCEPTED>
IF REJECTED: <what happens next>
REPLY: "ok <CARD>" or "no <CARD>: <reason>"
```

Rules: no card is issued with a missing evidence row (the row is shown as `NOT_RUN` and the result is `INSUFFICIENT_EVIDENCE`); a card never contains secrets; accepting a card is recorded in the matching document with the date and the reply text.
