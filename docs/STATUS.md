## 3. Ждёт владельца (не «просто CI»)

- Smoke **P37**: Attach → дерево (не один `.zip`) → privacy → вопрос агенту.
- **MANUAL1** — live Simple/Expert после MP3.
- **RM-*** / gates G2–G4 — Railway, провайдеры, GitHub App, пилот (`OWNER_OPS.md`).
- Оплата / квоты Gemini, BYOK — по решению владельца.
- Vision/OCR в scope — только если явно скажете.

---

## 4. Нельзя без новой явной команды

- Выполнение пользовательского кода на сервере Railway.
- Тихий push в GitHub `main` / write без ADR-06 и команды.
- Откат extract (P35) или ChangeSet-контракта (P36) «заодно».
- Слияние двух ТЗ в один монолит без решения владельца.
- Удаление с GitHub путей из `HISTORY_OFFREPO.md` **без** локальной копии у владельца.
