## Changes

- Added `src/workspace/tar.ts`: non-executing POSIX tar reader with checksum validation, PAX path metadata and GNU long names; links and special entries are never followed.
- Extended `src/workspace/ingest.ts` to detect ZIP, tar, gzip-tar by signature and accept folder file iterables.
- Added `src/workspace/idbStore.ts`: IndexedDB store, hash verification, atomic version/head write, persistence request and 85% quota warning helper.
- Added `src/workspace/context.ts`: privacy-gated WORKSPACE block, excluded-file filtering, bounded file reads, content search, `needFiles` / `needSearch` validation and a maximum-two-round follow-up helper.
- Added `tests/workspace-a2.test.mjs`; wired `test:p26a2` into `npm run check`; updated `CHANGELOG.md`, `docs/CURRENT_STATE.md`, `docs/NEXT.md`, `docs/REPO_MAP.md`.
