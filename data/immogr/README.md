# ImmoGR data workspace

This directory is reserved for ImmoGR-only research, source snapshots that may lawfully be retained, run reports, and reviewed listing evidence.

- Do not copy, read, or migrate data from data/immofinder/ or immofinder_* database tables.
- Never commit personal contact details, owner names, private addresses, raw listing content, or unredacted page captures.
- Store source research with access/terms review, observation date, and public source URL.
- Store candidate records only after the ImmoGR quality and provenance gates are implemented.
- At WP1, no live search or listing persistence is enabled.
