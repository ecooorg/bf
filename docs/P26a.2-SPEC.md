# P26a.2 SPEC — tar/folder ingest, IndexedDB and workspace context

**Status:** Implementation slice; AC-04 UI acceptance remains a gate.
**Base:** `bf-v26a.zip` (owner reports CI green).

## Scope

1. Read POSIX tar and gzip-compressed tar by signature; support PAX paths and GNU long names. Never follow links or execute archive content.
2. Accept folder-picker/dropped file iterables through a browser-side ingest helper. Reuse path normalization, skip rules, entry limits and content classification.
3. Add `IndexedDbWorkspaceStore` using `bifurcation_workspaces_v1` with `workspaces`, `versions`, `blobs`; atomically write version + head, verify blob hashes, request persistent storage for first workspace, expose quota warning at 85%, clean orphaned workspace blobs.
4. Add privacy-gated deterministic WORKSPACE context, safe file reads, content search, and bounded `needFiles` / `needSearch` response validation/orchestration. Excluded flags never enter default context.
5. Add tests and wire them into `npm run check`; update repository docs and report.

## Defaults chosen

- No new dependency: gzip uses platform `DecompressionStream`; unsupported browsers return a clear ingest rejection.
- Folder ingest and tar ingest are pure client-side helpers; this slice does not add a server workspace API or persist workspace references into chat/decision state.
- The context contract is implemented as reusable helpers. The Simple/Expert UI and end-to-end fake-Gemini conversation are not yet wired; therefore AC-04 is not claimed PASS.
- Product version remains 24, consistent with the P26a base archive and current P25 version gate; this patch is an incremental P26 feature slice, not the P25 release/version bump.

## PASS criteria

- `npm run test:p26a` and `npm run test:p26a2` pass.
- `node scripts/check-docs.mjs` and `node scripts/check-version.mjs` pass.
- Tar/gzip/folder fixtures are ingested deterministically; privacy gating and excluded-file handling are tested; model follow-up is bounded.
- AC-04 Simple/Expert fake-Gemini UI scenario remains `NOT_RUN` until end-to-end wiring is implemented.
